멍냥공장 개인정보처리방침

시행일: 2026년 10월 15일

1. 이 도구는 무엇인가요

멍냥공장은 운영자가 본인의 YouTube 채널 영상 정보(제목, 설명, 자막, 태그, 댓글)를 정리하기 위해 개인적으로 만들어 쓰는 도구입니다. 일반 이용자를 대상으로 하지 않습니다.

2. 어떤 정보에 접근하나요

Google 로그인(OAuth)을 통해 운영자 본인 채널의 YouTube Data API 및 YouTube Analytics API에 접근합니다. 접근 범위는 영상 정보 수정과 채널 통계 조회로 한정됩니다.

3. 정보는 어디에 저장되나요

Google이 발급한 접근 토큰과 조회한 채널 통계는 운영자가 소유한 컴퓨터에만 저장됩니다. 외부 서버로 전송하거나 제3자에게 제공하지 않습니다.

4. Google 사용자 데이터 정책

이 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 접근 철회

운영자는 언제든지 Google 계정 권한 페이지에서 이 도구의 접근을 철회할 수 있습니다.
