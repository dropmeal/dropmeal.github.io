1. 이 도구는 무엇인가요

멍냥공장은 운영자가 본인의 YouTube 채널을 관리하기 위해 개인적으로 만들어 쓰는 도구입니다. 일반 이용자를 대상으로 하지 않으며, 다른 사람에게 제공하지 않습니다.

2. YouTube API 서비스 사용

멍냥공장은 YouTube API 서비스를 사용합니다. 이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google 개인정보처리방침이 적용됩니다.

3. 어떤 정보에 접근하고 어떻게 사용하나요

Google 로그인(OAuth)으로 운영자가 허락한 경우에만 운영자 본인 채널의 YouTube Data API와 YouTube Analytics API에 접근합니다. 사용 목적은 다음으로 한정됩니다.

  • 운영자가 만든 영상을 본인 채널에 업로드
  • 영상의 제목, 설명, 태그, 썸네일, 자막, 다국어 정보 설정
  • 본인 영상의 재생목록 추가와 댓글 작성, 예약 공개 설정
  • 본인 채널 통계 조회

4. 정보는 어디에 저장되고 누구와 공유하나요

Google이 발급한 접근 토큰과 조회한 채널 정보·통계는 운영자가 소유한 컴퓨터에만 저장됩니다. 외부 서버로 보내거나 제3자에게 제공·판매하지 않습니다. 이 도구는 쿠키를 사용하지 않으며, 다른 사람의 기기에서 정보를 수집하지 않습니다.

5. Google 사용자 데이터 정책

이 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 접근 철회와 데이터 삭제

언제든지 Google 계정 보안 설정의 권한 페이지에서 이 도구의 접근을 철회할 수 있습니다. 철회하거나 이메일로 요청하면, 운영자 컴퓨터에 저장된 토큰과 YouTube 관련 데이터를 7일 이내에 삭제합니다. 그 밖의 YouTube 데이터는 YouTube API 서비스 정책이 허용하는 기간 동안만 보관하며, 최소 30일마다 승인 상태를 다시 확인하고 필요 없는 데이터는 삭제하거나 새로 고칩니다.

Mungnyang Factory Privacy Policy

Effective date: November 1, 2026

1. About this tool

Mungnyang Factory (멍냥공장) is a private tool built and used only by its owner to manage the owner's own YouTube channels. It is not offered to the public or to any other user.

2. Use of YouTube API Services

Mungnyang Factory uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

3. Information accessed and how it is used

Only after the owner signs in with Google OAuth and grants permission, the tool accesses the YouTube Data API and YouTube Analytics API for the owner's own channels. It is used only to:

  • Upload videos created by the owner to the owner's channels
  • Set titles, descriptions, tags, thumbnails, captions and localized metadata
  • Add the owner's videos to playlists, post comments on them, and schedule publishing
  • Read the owner's channel statistics

4. Storage and sharing

OAuth tokens and retrieved channel data and statistics are stored only on a computer owned by the owner. They are never sent to external servers, shared with, or sold to any third party. The tool does not use cookies and does not collect information from anyone else's device.

5. Google API Services User Data Policy

This tool's use of Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

Access can be revoked at any time through the Google security settings page. Upon revocation or an email request, stored tokens and YouTube data on the owner's computer will be deleted within 7 days. Other YouTube data is kept only as long as permitted by the YouTube API Services policies; authorization is re-checked at least every 30 days, and data that is no longer needed is deleted or refreshed.
